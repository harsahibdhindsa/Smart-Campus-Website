# Smart Campus Website

## Description
The Smart Campus Website is a modern and responsive web platform designed to simplify campus management and improve communication between students, faculty, and administrators. The platform provides features such as student login, timetable management, attendance tracking, announcements, event updates, and academic resources in one centralized system, creating a smarter, faster, and more connected campus experience.

## Features
- Secure Student Login System
- Timetable and Schedule Management
- Attendance Tracking System
- Campus Announcements and Notifications
- Event and Activity Updates
- Academic Resources Access
- Responsive and User-Friendly Interface
- Centralized Campus Information System
- Easy Navigation Across Devices
- Improved Communication Between Students and Faculty

- HTML
- CSS
